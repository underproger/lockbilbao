# Cerrajero24 — главная (RU, черновик перед переводом на ES)

Статичный проект без сборки: `index.html` + `css/style.css` + `js/main.js`.
Открыть локально: `python3 -m http.server` в папке проекта → http://localhost:8000

## Структура

Все внутренние ссылки и пути к ресурсам — относительные (без `/` в начале): сайт работает и в корне домена, и в подпапке
(например, `front.touchit.vinnica.ua/lockbilbao/`). Новые ссылки добавлять так же: с главной — `servicios/…`, со страницы услуги — `../../…`.

```
index.html          главная: разметка + schema.org (Locksmith, WebSite, WebPage, FAQPage)
servicios/index.html
                    каталог услуг (CollectionPage + ItemList, BreadcrumbList, FAQPage)
servicios/apertura-de-puertas/index.html
                    страница услуги «Аварийное открытие квартир» (BreadcrumbList, Service, FAQPage)
contacto/index.html контакты (ContactPage, Locksmith + contactPoint, BreadcrumbList, FAQPage)
404.html            страница «не найдено» (noindex), подключается через .htaccess
css/style.css       общие стили, токены в :root, адаптив 1320 / 1180 / 1024 / 760 / 380
css/service.css     блоки страниц услуг (подключается после style.css)
js/main.js          меню, параллакс hero, слайдер услуг, табы, слайдер отзывов, FAQ, карта, формы, модалка
fonts/              Inter, Inter Tight, Marck Script (woff2, локально — без Google Fonts)
img/                webp-ассеты, logo, favicon, og-image.jpg
img/services        иконки услуг (webp 360×360, прозрачный фон)
robots.txt, sitemap.xml
```

## Формы

В `js/main.js` → `CONFIG.formEndpoint`. Пока пусто — демо-режим (показывает успех без отправки).
Отправляется `FormData`: `name, dial, phone, phone_full, service, area, photo, consent, page, utm_*`.
Для испанского номера проверяется формат 9 цифр (6/7/8/9…); номер, вставленный с `+380…`, `+33…` и т.д., сам переключает код страны.

и мобильная `map-gran-bilbao-m.webp` (через `<picture>`, до 760px). На ней Бильбао, зона Гран-Бильбао (26 муниципалитетов,

## Перевод на испанский

Весь текст в HTML (JS содержит только зоны выезда, подписи кнопок и сообщения форм).
Ссылки на будущие страницы уже в испанских слагах: `/servicios/…`, `/zonas/…`, `/blog/…`.
В `<head>` закомментирован блок `hreflang` для `es-ES` / `ru-ES`.

## Страницы услуг

Шаблон — `servicios/apertura-de-puertas/index.html`. Пути к ресурсам относительные (`../../css/…`),
поэтому страница работает и в корне домена, и в подпапке. `js/main.js` сам определяет корень сайта
по адресу скрипта (Leaflet, картинка в центре карты).

Не называть классы `adv`, `ad`, `ads`, `banner`, `sponsor`, `promo` и т.п. — блокировщики рекламы (EasyList) скрывают такие элементы.

Общие блоки с главной: шапка, футер, слайдер отзывов, карта районов с проверкой адреса, FAQ, финальная форма, модалка.
Новые блоки страницы (в `css/service.css`): хлебные крошки, hero услуги, под ним — тёмная плашка с преимуществами и формой (`.quick`),
ситуации 3×2, цены + примечания, «формула» цены (`.calc`: 4 фактора + итог), призыв вызвать мастера с формой, «без повреждений», преимущества, документы, другие услуги — слайдер из 8 карточек главной (все, кроме текущей).

На сайте только 9 услуг из блока «Услуги» на главной — ссылок на другие страницы (районы, «Наши работы» и т.п.) нет.

Перед публикацией страницы «Открытие квартир»:
- цены в таблице — `от … €`, заполнить после утверждения прайса; строка IVA в примечаниях — `[…]`;
- отзывы — примеры («Пример отзыва»), нужны настоящие отзывы именно об открытии квартир;
- карточка «Электронные замки» — оставить, только если услуга реально оказывается.

## Страница 404

`404.html` в корне, подключается через `.htaccess` (`ErrorDocument 404`). Сервер отдаёт её по любому несуществующему адресу,
поэтому пути на ней считаются от корня сайта через `<base href="/lockbilbao/">`.
При переносе в корень домена поменять в двух местах: `<base href="/">` в `404.html` и `ErrorDocument 404 /404.html` в `.htaccess`
(для nginx — `error_page 404 /404.html;`).

## Общие блоки

Шапка, футер, заявка, мобильная панель, плавающие кнопки и модалка — одинаковые на всех страницах, эталон — `index.html`.
Каталог `/servicios/` пересобирается из главной (скрипт сборки + шаблон каталога), на остальных страницах блоки
вставлены с поправкой путей (`../`, `../../`). При правке общего блока — обновить его на всех страницах.

SEO-текст («Полезно знать»): разметка `[data-more]` / `[data-more-body]` / `[data-more-btn]`, свёрнутая высота — `.longread.is-ready .longread__body { max-height }`.
Без JS текст показан целиком; если текст короче свёрнутой высоты, кнопка не появляется.
