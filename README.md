# LockBilbao — главная (RU, черновик перед переводом на ES)

Статичный проект без сборки: `index.html` + `css/style.css` + `js/main.js`.
Открыть локально: `python3 -m http.server` в папке проекта → http://localhost:8000

## Структура

```
index.html          разметка + schema.org (Locksmith, WebSite, WebPage, FAQPage)
css/style.css       стили, токены в :root, адаптив 1320 / 1180 / 1024 / 760 / 380
js/main.js          меню, параллакс hero, слайдер услуг, табы, слайдер отзывов, FAQ, карта, формы, модалка
fonts/              Inter, Inter Tight, Marck Script (woff2, локально — без Google Fonts)
vendor/leaflet/     Leaflet 1.9.4, грузится лениво при подлёте к блоку «Районы»
img/                webp-ассеты, logo, favicon, og-image.jpg
img/services        иконки услуг (webp 360×360, прозрачный фон)
robots.txt, sitemap.xml
```

## Порядок блоков (экраны из ТЗ)

## Формы

В `js/main.js` → `CONFIG.formEndpoint`. Пока пусто — демо-режим (показывает успех без отправки).
Отправляется `FormData`: `name, dial, phone, phone_full, service, area, photo, consent, page, utm_*`.
Для испанского номера проверяется формат 9 цифр (6/7/8/9…); номер, вставленный с `+380…`, `+33…` и т.д., сам переключает код страны.

## Карта

OpenStreetMap-тайлы через Leaflet. Для коммерческого трафика лучше подключить MapTiler / Stadia по ключу (`L.tileLayer` в `initMap`).
Тайлы тонируются под палитру сайта SVG-фильтром `#map-tint` (в разметке блока «Районы»), фильтр стоит на каждом тайле.
Зум только целый (`zoomSnap: 1`): при дробном Chrome масштабирует тайлы и между ними видны швы.
Города с подписями на карте и сторона подписи — `MAP_TOWNS` в `js/main.js`; если карте не хватает места под подписи, она переходит в компактный режим (только точки).

## Перевод на испанский

Весь текст в HTML (JS содержит только подписи счётчика hero, зоны выезда и сообщения форм).
Ссылки на будущие страницы уже в испанских слагах: `/servicios/…`, `/zonas/…`, `/blog/…`.
В `<head>` закомментирован блок `hreflang` для `es-ES` / `ru-ES`.
FAQ JSON-LD собран из разметки FAQ — при переводе обновить и его.
