# CerrajeroUCR — тема WordPress

Тема для сайта аварийного слесаря CerrajeroUCR (Бильбао и Гран-Бильбао), собрана из статической вёрстки репозитория 1:1.
Языки: **испанский (Испания, es_ES) — основной, без префикса в URL**, **баскский** (`/eu/`), **английский** (`/en/`, en_GB).

## Требования

- WordPress 6.5+, PHP 8.0+
- Secure Custom Fields (или ACF Pro)
- Polylang Pro 3.5+ (на бесплатном Polylang тоже работает, но без переводимых слагов родителя)
- Contact Form 7
- Yoast SEO — по желанию: если он стоит, title/description/OG выводит Yoast, а значения из полей темы подставляются, когда в Yoast пусто.

## Установка

1. Установить и активировать плагины: Secure Custom Fields, Polylang Pro, Contact Form 7.
2. Загрузить `cerrajero24.zip` в «Внешний вид → Темы → Добавить» и активировать.
3. «Настройки → Постоянные ссылки» → «Название записи» (`/%postname%/`).
4. Запустить импорт: «Инструменты → Импорт CerrajeroUCR» или `wp c24 import`.

Импорт создаёт всё сам:

- языки Polylang: es_ES (по умолчанию, без префикса), eu, en_GB; язык в URL — каталогом (`/eu/`, `/en/`);
- медиа из `assets/img` с alt на трёх языках (у каждого языка своё вложение);
- 16 страниц × 3 языка со связями переводов: главная, «Услуги» (шаблон «Каталог услуг»), 9 услуг — дочерние страницы «Услуг» с шаблоном «Услуга», «Контакты», 4 юридические страницы;
- меню шапки, мобильного меню и подвала для каждого языка;
- переводы строк темы (Polylang → «Переводы строк», группа CerrajeroUCR);
- форму Contact Form 7 и контакты на странице опций.

Повторный запуск обновляет те же страницы (ищутся по скрытому ключу `_c24_key`) и не создаёт дубли — но **перезаписывает тексты** из `import/*.json`. После правок в админке импорт повторно не запускать.

### Адреса

| | ES | EU | EN |
|---|---|---|---|
| Главная | `/` | `/eu/` | `/en/` |
| Каталог | `/servicios/` | `/eu/zerbitzuak/` | `/en/services/` |
| Услуга | `/servicios/apertura-de-puertas/` | `/eu/zerbitzuak/ateak-irekitzea/` | `/en/services/door-opening/` |
| Контакты | `/contacto/` | `/eu/kontaktua/` | `/en/contact/` |

Слаги испанских услуг совпадают со статической версией. Полный список — `i18n-src/tools/slugs.json` в репозитории.

## Обновление темы на рабочем сайте

1. Загрузить новый `cerrajero24.zip` поверх старой темы («Заменить текущую версию»). Папка темы остаётся `cerrajero24`, внутренние префиксы функций — `c24_`; это не видно посетителям.
2. Запустить «Инструменты → Импорт CerrajeroUCR». Повторный импорт:
   - обновляет тексты страниц, меню, alt картинок и переводы строк из файлов темы;
   - если картинка в теме изменилась (например, фото мастера), загружает новый файл под новым именем;
   - **не трогает** получателей письма в форме CF7, если их меняли в админке (заменяется только заглушка `info@cerrajero24.es`);
   - в «Контактах» заполняет пустые поля и заменяет только заглушки со старым названием;
   - исправляет название сайта, если оно пустое, старое или набрано с кириллическими буквами;
   - отправляет в корзину стандартные «Sample Page» / «Hello world!», если их не редактировали.

## Плагины на сайте

- **Yoast SEO**: если в Yoast для страницы не заполнены SEO-заголовок, описание и OG-поля, берутся поля темы (вкладка «SEO»). Картинка для соцсетей по умолчанию — `assets/img/og-image.jpg`. Разметку schema.org на страницах темы выводит тема, граф Yoast на них отключён (чтобы не было двух WebSite/WebPage).
- **WP Armour (Honeypot)**: проверяет поле, которое его скрипт вставляет только в стандартную разметку CF7, а формы темы свёрстаны своей разметкой и отправляются через REST API. Поэтому для заявок с форм темы проверка WP Armour снимается, а вместо неё работает защита темы: `main.js` добавляет в заявку метку `c24_token`, и без JavaScript (как у типичного бота) заявка помечается как спам. Остальные формы — вход, комментарии, другие формы CF7 — WP Armour проверяет как обычно.
- **Contact Form CFDB7**: заявки сохраняются в «Contact Forms» в админке.

## Редактирование

- **Страницы** — все блоки в полях SCF, разбиты по вкладкам в порядке секций на странице. Набор полей зависит от шаблона: «Главная» (главная страница), «Каталог услуг», «Услуга», «Контакты»; у юридических страниц — обычный редактор.
- **Карточки услуг** (слайдеры на главной, в каталоге и «Другие услуги») берутся со страниц услуг, вкладка «Карточка»: название, текст, цена «от», иконка, группа в каталоге. Порядок — поле «Порядок» (Атрибуты страницы).
- **Цены** — в каждой услуге (вкладка «Цены»), на главной и в каталоге (блок «Цены»). Пустая цена выводится как «a consultar / galdetu / on request», `…` — как «desde … €» (место под цену).
- **Контакты** — меню «Контакты» в админке: телефон, WhatsApp, e-mail, ссылки на Google Maps и отзывы, рейтинг и число отзывов, NIF, логотипы. Общие для всех языков.
- **SEO** — вкладка «SEO» на каждой странице: title, description, описание для соцсетей, у услуг — данные для schema.org Service. hreflang выводит Polylang: `es-ES`, `eu-ES`, `en-GB` и `x-default` → испанская версия. Разметка schema.org (Locksmith, Service, BreadcrumbList, FAQPage) собирается из полей.
- **Строки интерфейса** (кнопки, подписи форм, сообщения) — Polylang → «Переводы строк». Испанский — исходный текст в коде.

Polylang Pro при сохранении одной языковой версии не трогает поля других языков (проверено).

## Формы

Вёрстка форм — в теме (`inc/cf7.php`), отправка — через REST API Contact Form 7 в одну форму «CerrajeroUCR — заявка». Сообщения об ошибках и об успешной отправке — на языке страницы. Письмо уходит на e-mail из «Контактов»; в нём: форма и страница, услуга, имя, телефон с кодом страны, адрес/район, «что случилось», фото (во всплывающей форме), UTM-метки.

Адрес получателя и тему письма можно поменять в «Контакт → CerrajeroUCR — заявка → Письмо». Поля формы в CF7 не переименовывать — на них завязан скрипт. Шаблон формы тема обновляет сама при выходе новой версии (получатели и тема письма не меняются).

## Что заполнить перед запуском

Как и в статической версии, часть данных — заглушки:

- телефон `+34 944 123 456`, WhatsApp, e-mail `info@cerrajeroucr.es`, домен;
- NIF/CIF и юридические данные (подвал, «Aviso legal», политики);
- ссылки на профиль Google и рейтинг;
- цены `… €` в таблицах услуг (установка, ремонт и т. д.) и строка про IVA `[…]` в примечаниях к ценам;
- отзывы помечены как «пример отзыва» — заменить на настоящие.

## Структура

```
cerrajero24/
├── style.css, functions.php
├── header.php, footer.php, front-page.php, page.php, index.php, 404.php
├── templates/        page-services.php, page-service.php, page-contacts.php
├── template-parts/   общие блоки: цены, преимущества, процесс, отзывы, районы, лонгрид, FAQ, заявка, модалка, спрайт
├── inc/
│   ├── setup.php     поддержка темы, меню, подключение CSS/JS, шрифты
│   ├── helpers.php   опции, телефоны, картинки, ссылки, районы, данные для JS
│   ├── acf.php       группы полей и страница опций
│   ├── polylang.php  регистрация строк
│   ├── cf7.php       разметка форм и связка с CF7
│   ├── seo.php       title/meta/OG, hreflang, schema.org
│   └── import.php    импорт контента (админка и WP-CLI)
├── import/           pages.json (структура), es.json, eu.json, en.json (тексты), strings.json (строки интерфейса)
└── assets/           css, js, fonts, img — из статической вёрстки
```

Исходники переводов (по сегментам, с номерами) лежат в репозитории в `i18n-src/`; `import/*.json` собираются из них скриптом `i18n-src/tools/seg.py build <lang>`.
